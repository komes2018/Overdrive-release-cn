RoadSense 路况感知
关
启用 RoadSense
透过动态与 GPS 检测道路危害（颠簸、坑洞、减速带），并在接近已知危害前发出警告。仅在此功能启用时，所有其他 RoadSense 设置才会生效。
地图
打开地图
打开全屏地图来搜索路线，导航并看到道路上的道路危险。点击任何危险来确认或删除它。
路由
没有路由键
底图数据完全免费。逐向路线规划需要填写来自 Valhalla 服务商的免费个人 API 密钥。此项为选填：即使未配置密钥，地图与路况警示仍可正常工作。你的密钥将加密保存在车机本地。
如何获得免费路由密钥
  1. 点击“获取免费密钥”打开 Stadia Maps 注册页面，然后创建免费账户（免费套餐无需信用卡）。
  2. 在仪表盘中，打开属性并创建属性，然后转到身份验证和 API 密钥。
  3. 点击"创建 API 密钥"并复制它显示给你的密钥字符串。
  4. 粘贴到下面的“路由API密钥”字段，然后点击保存。将端点作为默认值。
路由终点
Valhalla兼容的路由URL。请保留为默认，除非你的供应商给你一个不同的路由。
路由 API 密钥
你的个人BYOK 密钥。已存储的加密设备，在保存后不再显示。

检测
检测灵敏度
RoadSense 识别颠簸、坑洼或减速带的灵敏度。默认调校为 50%。滑块调高可捕捉更轻微的路面颠簸（但误报可能会增多）；滑块调低则仅标记明显强烈的路面冲击。此项控制检测识别阈值，与下方的预警最低可信度阈值不同。

标定模式
在悬浮窗口中确认检测结果
在屏幕悬浮窗口上显示每个检测到的危害，并提供确认/修正按钮，以便你告知 RoadSense 哪些检测是真实的。在几次行驶中使用此功能来微调适合你车辆的检测，然后将其关闭。
屏幕叠加显示
在屏幕上显示悬浮卡片画面
在屏幕上显示悬浮的 RoadSense 胶囊卡片与路况预警。关闭此项可隐藏浮窗 — 隐患检测、语音告警和路况众包仍会在后台正常运行，仅隐藏屏幕界面显示。

盲区
关
启用盲区监测
当你打开转向灯时，在浮动窗口中显示一个合并的后方+侧摄像头视图。 尺寸和位置设置在下方。左侧信号显示后方+左；右侧信号显示右侧+后方。
显示摄像头
将后方摄像头和侧边摄像头合并为一个视图，或只显示一个摄像头。 单摄像头视图用摄像头的整个视场填充窗口；混合点和混合软滑块只适用于合并视图。
旋转视图 — 左侧
旋转屏幕上左转（左侧摄像头）的视图。当左侧摄像头竖过来更易于查看时很有用。窗口会随旋转调整形状。40° 与 310° 是现成的盲区取景默认，各自已内置裁剪、镜像与缩放，无需再做其他调整。
前进方向 — 左侧
前进行驶时使用的角度。挂入倒挡时画面翻转 180°，倒车时看起来更自然。
旋转视图 — 右侧
旋转屏幕上右转（右侧摄像头）的视图。右侧摄像头与左侧呈镜像，因此通常需要不同的角度。窗口会随旋转调整形状。40° 与 310° 是现成的盲区取景默认，各自已内置裁剪、镜像与缩放，无需再做其他调整。
前进方向 — 右侧
前进行驶时使用的角度。挂入倒挡时画面翻转 180°，倒车时看起来更自然。
鱼眼校正
