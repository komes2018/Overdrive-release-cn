你的自动化

尚未配置自动化。请添加一个自动化。

创建一个自动化，在车辆事件符合你的条件时触发操作。

设置
允许 Shell 操作
允许自动化在条件符合时自动运行原始 Shell 命令。此操作会在后台无人值守运行 —— 除非你确定自己的自动化会执行什么操作，否则请保持关闭。
备份和恢复
导出/导入
将你所有的自动化保存到一个文件，或从备份中恢复。导入时会合并到你当前的自动化中（相同 ID 的现有自动化将被替换）。
音频库
上传声音
上传 MP3、WAV 或 MP4 音频文件（最大 16 MB）。“播放音频”动作和按键映射可以播放这里的任意音效。
行车主动安全防护规则
这些安全防护适用于通过 OverDrive 自动化、操作组、按键映射、快捷控制、MQTT、车控面板及座椅记忆触发的车辆动作。关闭某项防护后，OverDrive 将允许在行车过程中或状态未知时尝试该操作。高级原始 Shell、CAN 和底层诊断操作不受此防护限制。
正在加载安全防护配置…
车门加锁与解锁
除非车辆处于安全驻车状态，否则阻止锁定或解锁车门。
后备箱/尾门动作
阻止行车中开启或关闭后备箱。停止动作不受限制。
外后视镜折叠
阻止行车中折叠外后视镜。展开动作不受限制。
座椅、方向盘与后视镜位置调节
阻止行车中调用座椅记忆和位置调节。原车可能仍需驻车挡才能响应。
关闭大灯
阻止将车灯挡位切换至关闭。自动 (AUTO)、示宽灯和近光灯不受限制。
屏幕亮度调节
阻止行车中自动调节中控屏、仪表盘和 HUD 亮度。
屏幕电源控制
阻止中控息屏和关闭 HUD。开启 HUD 不受限制。
全屏多媒体播放
阻止行车中弹出全屏视频播放。纯扬声器音频播报不受限制。
