<a id="国内车机优化"></a>
## 🇨🇳 国内车机深度优化专版说明（重点特性）

针对国内比亚迪车主的真实用车场景、网络环境以及原生 DiLink 车机系统，本项目进行了全方位的本土化重构与专项优化：

### 1. 企业微信 / 钉钉 / 飞书直连推送（国内免代理）
- **哨兵现场图文秒推**：触发哨兵告警时，自动将触发方位、目标行为、可信度、12V 小电瓶与动力电池状态及 **4 路现场抓拍拼图** 直推到微信/企业微信群，国内网络直达无需任何代理。
- **驻车耗电报告 (`ParkingDrainTracker`)**：每次熄火驻车后重新点火时，自动结算并推送停放总时长、动力电量消耗及 12V 小电瓶电压变化，支持跨更新/重启基准线持久化。
- **行程结束报告 (`TripNotifier`)**：每次行程结束熄火后，自动汇总行驶里程、耗时、电耗、驾驶评分与预估费用并推送到群机器人。

### 2. 车规级全量中文精校与零延迟首屏
- 对 **Web 前端 3,700+ 条**、**守护进程服务端推送 1,200+ 条** 及 **Android 原生 1,280+ 条** 文本进行了逐行人工车规级精校，并通过 CI 术语表门禁（`scripts/i18n_check.py`）杜绝机翻和繁体残留。
- 原生中文零延迟首屏加载，彻底消除 Web 控制台打开时的英文闪烁（FOUC），日期全局采用直观的 `YYYY-MM-DD HH:mm:ss` 中文格式。

### 3. 超低功耗熄屏驻车与 12V 防亏电治理
- **真实背光断电**：熄屏运行直接调用底层背光切断（DiLink 5 走 `StealthPanel`），并非“亮度调 0”假黑屏，同时自动停用无用高德后台进程以释放 GNSS 卫星硬件。
- **CPU 与唤醒锁长稳优化**：静止自动降帧率、消除空载编码与安全区重入自旋；引入 5 分钟双唤醒锁自动续租，根治长停满 6 小时掉锁失联问题。
- **实测表现**：经过 `v49.9.37~v49.9.39` 实车隔夜测试，四进程合计平均 CPU 仅约 `7.5%`（占 8 核总算力 `<1%`），全天候待机功耗约 **`7W ~ 12W`**（静态隔夜实测平均约 `7W`，26 小时仅掉电 `1% SOC`）。

### 4. 国内大内网穿透与热更新免断联运维
- **5 种远程互联通道**：支持局域网直连、**Tailscale**（支持 HTTPS 安全源与远程 ADB）、**WireGuard / EasyTier 桥接**（支持内网主机直连与远程 ADB 5555 映射）、**Zrok**、**Cloudflare Tunnel**。
- **远程升级不掉线**：`tailscaled` 与 `adbd` 独立于主程序常驻；APK 采用固定签名指纹构建，支持 `pm install -r` 平滑覆盖升级，全车配置持久化保存于 `/data/local/tmp/overdrive_config.json`，升级不丢设置。

### 5. 国内车机专属体验增强
- **本地车控脱离云端 & 5G 月流量统计**：不依赖官方云即可实现本地车控，首页仪表盘实时展示车机 SIM 卡 5G 当月用量状态条，并在充电页追踪 **动力电池健康度（SOH）** 估算曲线。
- **DiLink 5.0 深度兼容**：支持 Qualcomm QCarCam 用户态免 root 4 路取流与 QNX 驻车网络保活。

<a id="零流量千里眼方案"></a>
## 📡 零成本/低流量「24h 远程千里眼」实战方案

比亚迪原厂车机赠送流量有限且熄火后官方 App 监控受限，OverDrive 提供了免破线、极低成本的全天候解决方案：

1. **开启 USB 驻车常电**：在 Web 端 **「哨兵监控」** 中打开 **「停车时保持 USB 供电」**。车辆熄火锁车后 USB 口仍持续稳定供电（不影响摄像头与驻车哨兵）。
2. **即插即用随身 Wi-Fi**：在车机 USB 口插一个几十元的免插卡 4G/5G USB 随身 Wi-Fi（年包通常几十元几百 GB），车机连接该热点即可全天不断网。
3. **手机随时随地看车**：搭配 **Tailscale** 或 **WireGuard**，随时秒开 **4 路高清环视实时画面**、回放下载哨兵录像、接收 **企业微信/Telegram 抓拍告警**，并随时巡检 **动力电池 SOH / SOC** 与 **12V 小电瓶电压**。

<a id="功耗实测与防亏电双保险"></a>
## 🔋 功耗实测与 12V 小电瓶防亏电双保险

| 耗电部件 | 运行状态 | 实测功率 |
|---|---|---|
| USB 随身 Wi-Fi | 4G/5G 蜂窝保活 | 1W ~ 1.5W |
| 车机主板熄屏运行 | 静态四进程总 CPU 约 7.5%（**背光轨真实断电**） | 2.5W ~ 5W |
| 4 路环视相机 + ISP | 驻车低帧率捕获 | 2.5W ~ 4W |
| YOLO AI 推理 | 仅画面发生变动时按需介入 | 0W ~ 2W |
| **整套系统合计** | **全天候待机（实车隔夜约 7W，约 0.2~0.3 度/天）** | **约 7W ~ 12W** |

- **第一道保险（原车高压智能补电）**：当 12V 小电瓶电压下降时，比亚迪整车控制器（VCU）会自动唤醒高压 DC-DC 从动力大电池为其充电，实测隔夜小电瓶稳守 `13.0V ~ 13.8V`。
- **第二道保险（内置低电量停止门控）**：Web 端 **「哨兵监控 → 低电量停止」**（默认 **10%**，可调 `0%` 关闭 ~ `30%`）监测到动力电池 SOC 跌破阈值且非充电状态时，经 60 秒防抖确认后自动释放 WakeLock、熄屏休眠并退出守护进程。

> 详细功耗对比与长期停放建议见 [《车友安装使用指南》第 7 章](docs/USER_GUIDE.md#7-耗电实测与-12v-小电瓶保护)。

## 核心功能特性

1. **雷达近距感应 + 驻车碰撞哨兵**：接入原厂 8 颗倒车雷达（RED `<0.5m` / YELLOW `0.5–0.8m` 分级，500ms 防抖与预录缓冲）与驻车碰撞检测，支持 **安全地点（Safe Locations）** 自动静默与定时计划。
2. **软硬解耦四路行车与哨兵录像**：支持 H.264 / H.265 硬件编码与原厂前视行车记录仪（`dvr_`）镜像同步，录像可叠显车速、挡位、踏板、转向灯及时间戳。
3. **防冲锁存（SafeKeep）与多存储介质**：重要事件支持防覆盖锁定，并支持本地内置存储、SD 卡、U 盘及 S3 / WebDAV / NAS 备份。
4. **物理按键映射与自动化规则引擎**：支持方向盘/中控键单击、双击、长按组合宏；内置 Trigger / Condition / Action 本地自动化编排引擎。
5. **盲区影像辅助 & 蓝牙靠近感知 & 桌面微件**：拨动转向灯自动弹出侧后方低延迟盲区视角；支持蓝牙靠近自动解闭锁、座椅记忆迎宾（Easy-Entry）与毛玻璃桌面微件。

## Home Assistant 本地双向智能家居联动

OverDrive 内置 MQTT 客户端与 Home Assistant 自动发现（支持中文实体名与固定 `entity_id`），**全程局域网 / Tailnet / WireGuard 直连，无须经过比亚迪云端**：

- **传感器实体**：电池电量（SOC）、电池健康度（SOH）、动态续航、行驶车速、实时经纬度、四轮胎压、座舱/电芯温度、充放电功率、四门/车窗/前后备箱/安全带状态。
- **车控实体（默认安全可配）**：空调开关/温度/风速/循环、全车窗升降、后备箱/天窗控制、主副驾座椅通风加热、无线充电板、交流慢充上限（50%~100%）等。

## 快速上手与安装指南

> 📖 **完整图文步骤（含防黑屏、停用路况监测、手机远程配置与排障）请直接阅读：[docs/USER_GUIDE.md](docs/USER_GUIDE.md)**

1. **下载安装包**：前往 [**GitHub Releases**](https://github.com/komes2018/Overdrive-release-cn/releases) 下载最新 `Overdrive-v*-cn-sec.apk`。
2. **开启车机调试并安装**：在车机开发者选项中开启 **USB 调试**，通过 U 盘或 `adb install -r` 安装进车机。
3. **首次授权与基础设置**：
   - 打开 App，在弹出「允许 USB 调试」框时务必勾选 **「一律允许」**；
   - 在弹出的 **「开始」** 引导框中放行 **自启动管理**（注：比亚迪每次更新都会重置自启动开关，升级后需重新确认）、授予 **悬浮窗权限**，并点击 **「停用比亚迪路况监测服务」**（解除原厂对第三方 App 联网的拦截）；
   - **关键硬重启**：长按中控台音量滚轮 / 电源键（部分车型为音量减键）**5 秒以上**触发硬件级重启，确保路况监测停用与摄像头守护进程生效。
4. **配置远程访问与推送**：
   - 按向导完成运行模式（`行车 + 驻车`）与摄像头配对（若反了点「对调交换」）；
   - 在 App 左侧栏 **「仪表板」** 复制 **「访问码」** 登录 Web 控制台；
   - 选配 **局域网 / Tailscale / WireGuard / Zrok / Cloudflare** 之一连接手机，并在 Web 端 **「通知 → 企业微信 / Webhook」** 填入群机器人地址。
