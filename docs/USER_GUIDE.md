## 0. 先花 30 秒搞清楚这是什么

**OverDrive 是一个运行在比亚迪车机本地，把「行车记录仪 + 驻车哨兵 + 远程千里眼 + 车辆数据面板」整合在一起的开源应用。**

它跟原厂记录仪最大的区别：

- **雷达近距哨兵**：接入**原车 8 颗驻车倒车雷达**，结合视觉与 AI 目标识别，只有物体/人员真靠近才触发录像，大幅减少树叶晃动、光线变化的误报。
- **四路环视录制**：同时采集 360° 全景拼接与前视行车记录画面，轻量化管线运行，CPU 占用极低。
- **手机远程看车**：车机内置 Web 控制台，手机连上就能实时看四路画面、回放下载录像、查电量和胎压、远程控车。
- **数据全在车机本地**：录像与行车轨迹 100% 存在本地（内置存储 / SD 卡 / U 盘），不经第三方云端，没有账号和月费。

## 1. 确认你的车能装

| 项目 | 要求 |
|---|---|
| 车机系统 | 比亚迪 DiLink 3.0 / 4.0 / 5.0 |
| Android 版本 | Android 10 或以上 |
| 处理器架构 | `arm64-v8a`（主流 DiLink 车机均满足） |
| 已验证车型 | 海豹、海豚、元 PLUS、汉、唐、秦 PLUS DM-i、宋 PLUS DM-i 等 |

> ⚠️ **风险提示**：OverDrive 属于第三方开源软件，并非比亚迪官方应用。它需要借助系统 ADB 权限调用摄像头和车控接口，安装前请自行评估，能接受再继续。

## 2. 第一步：开启调试并安装 OverDrive

### 2.1 下载安装包

前往项目的 **Releases 页面**下载最新的 `-cn-sec` 版本安装包（中文精校 + 安全加固版）：

```
https://github.com/komes2018/Overdrive-release-cn/releases
```

文件名形如 `Overdrive-v49.9.38-cn-sec.apk`（选最新版本即可）。

### 2.2 准备车机：开启「开发者选项」与「USB 调试」

这一步必须在**安装并运行 OverDrive 之前**完成：

- **为什么长期需要 USB 调试？**
  OverDrive 采用「App 主界面 + 后台守护进程」架构，守护进程需要以系统 Shell 权限运行才能读取 360° 摄像头并执行后台控制，因此 **USB 调试必须保持长期开启**（不是装完就能关的）。
- 在车机「系统设置 → 关于本机 / 版本信息」中按对应 DiLink 车型的常规方式进入**开发者选项**，打开 **USB 调试**（部分车型需同时打开无线调试/允许 ADB 调试）。

### 2.3 将 APK 装进车机（两种方式任选其一）

- **方式 A：U 盘安装（推荐新手）**
  1. 把下载好的 `.apk` 复制到 U 盘根目录
  2. 将 U 盘插到车机数据接口，打开车机自带「文件管理」找到 APK 点击安装
  3. 如提示「允许来自此来源的应用」，按提示开启一次即可
- **方式 B：电脑 / 手机 ADB 安装（若车机禁止 U 盘直装第三方 APK）**
  1. 车机连上与电脑同一局域网（或用双头 USB 线直连电脑）
  2. 在电脑终端运行：
     ```bash
     adb install -r Overdrive-v*-cn-sec.apk
     ```

## 3. 第二步：首次启动授权与基础设置

### 3.1 授权「允许 USB 调试」

首次打开 OverDrive 时，Android 系统会弹出「**允许 USB 调试吗？**」授权框：

> ✅ **务必勾选「一律允许」，再点击确认。**

若未弹出，可能是车机此前已授权过，引导流程会自动继续。

### 3.2 完成「开始」引导弹窗（首次必填）

授权后进入 App 首页会自动弹出 **「开始」** 设置弹窗（共三步加一个网络前置提示）：

1. **选择自己的语言**
   默认跟随车机系统语言，也可点此为 App 和 Web 控制台单独指定语言。
2. **禁用自动启动限制**
   点击 **「开启BYD自动启动」**，App 会尝试自动帮你放行后台限制；若自动操作失败而跳转到比亚迪「自启动管理」界面，请在列表中找到 OverDrive 并确保**允许其后台/开机自启动**（不同版本车机列表含义不同：若开关文字为“禁止自启”请**取消勾选**；若为“允许自启”请**勾选开启**）。
   > ⚠️ **每次覆盖更新 OverDrive 后，比亚迪系统都会重置此开关，更新完需重新确认一次。**
3. **允许在其他应用上层显示**
   授予悬浮窗权限，用于在地图/音乐等界面上显示录制与行程状态浮层。
4. **停用比亚迪路况监测服务（非常关键）**
   弹窗下方可找到 **「停用比亚迪路况监测服务」**（`BYD Traffic Monitor`）。
   - **为什么要停用？** 比亚迪原厂自带的路况监测服务会拦截第三方应用使用车联卡联网，且锁车后仍后台偷跑流量与耗电。停用仅关闭原厂自带地图的简易路况图层，**不影响高德/百度地图导航、蓝牙及一切行车功能**。
   - 点击按钮按提示停用即可（需前面 ADB 已授权成功才能执行）。

### 3.3 强制硬重启车机（必做）

完成上一步后，**不要用系统菜单里的“重启”**，请直接执行硬件级重启：

> **长按中控台下方的音量滚轮/电源键（部分车型为音量减键）5 秒以上，直至屏幕黑屏重新启动。**

**原因**：停用路况监测服务需要硬重启才会真正生效，同时 OverDrive 的底层摄像头守护进程也依赖系统冷启动注册；不硬重启容易出现「无法联网」或「画面全黑」。

### 3.4 新手向导与可选 PIN 锁

硬重启后再打开 OverDrive，会自动进入交互式新手向导：

- **选择运行模式**：
  - **行车 + 驻车（推荐）**：熄火后哨兵和后台监测继续运行；
  - **仅行车时**：熄火离车后自动停止后台守护，仅在行车时录像。
- **摄像头配对**：
  页面会显示两路实时预览，分别确认「360° 全景」和「行车记录仪」。如果两路画面反了，点击 **「对调交换」** 会立即互换并保存。
  > 🔧 若遇到画面全黑，可在 **诊断 → 摄像头探测器** 里将摄像头 ID 设为 `0` 保存并重启摄像头守护进程；仍不行可尝试 `1`。
- **（可选）设置 PIN 锁**：
  如果是共用车辆，可在 App 左侧栏 **设置 → 安全** 中设置 4–8 位 PIN 码，防止别人误改设置（锁定期间哨兵和录像照常运行）。
  > 忘记 PIN 码无需恢复出厂，通过电脑 USB 连接车机执行 `adb shell touch /data/local/tmp/.overdrive_pin_reset` 即可清除。

## 4. 第三步：让车机联网与手机远程访问

### 4.1 让车机持续联网（三种方式）

| 方式 | 适合谁 | 说明 |
|---|---|---|
| **车机自带车联卡** | 原厂流量充足的人 | 最省事；注意赠送流量到期后原厂续费较贵 |
| **手机热点** | 仅行车或偶尔看录像 | 离车就断网，**无法实现 24 小时远程监控** |
| **USB 随身 Wi-Fi（推荐）** | 想低成本 24h 全天候在线 | 搭配下方常电设置，年费几十元即可畅享大流量 |

**推荐组合：免插卡 USB 随身 Wi-Fi + 驻车 USB 常电**

1. 准备一个免插卡 4G/5G USB 随身 Wi-Fi（几十至百余元，年包通常几十元几百 GB）插在车机 USB 口，让车机连上它的热点。
2. 在 Web 控制台的 **「哨兵监控」** 页面开启 **「停车时保持 USB 供电」**。
3. 熄火锁车后，车机 USB 口仍保持供电，随身 Wi-Fi 全天在线，同时车载摄像头与哨兵照常工作。

### 4.2 让手机远程找到车机（四种方案）

#### 🔵 方案 A：局域网直连（新手先用它跑通）

手机和车机连同一个 Wi-Fi（或手机连车机热点），手机浏览器打开：

```
http://<车机局域网IP>:8080
```

- **优点**：零配置、推流延迟最低（`<100ms`）
- **缺点**：仅限同一局域网，人离开车就连不上了
- **建议**：先用局域网跑通确认画面、录像、控制一切正常，再配远程方案。

#### 🟢 方案 B：Tailscale 虚拟局域网（强烈推荐主力方案）

国内车联卡和随身 Wi-Fi 几乎都在运营商大内网里，没有公网 IP，传统端口映射无法使用。Tailscale 能将你的手机与车机直接组成加密虚拟局域网，穿透稳定且不走第三方中转限速。

**配置步骤**：
1. 在手机上安装 Tailscale 客户端并注册账号（个人免费版完全够用）。
2. 在车机 OverDrive 的 **集成 / 守护进程** 相关页面启动 Tailscale，点击生成**登录链接**，用手机或电脑浏览器打开完成设备授权（建议在 Tailscale 控制台禁用密钥过期，避免每半年重登一次）。
3. 授权完成后车机获得固定虚拟内网 IP，此后无论你在哪，手机打开 Tailscale 就能直接访问车机控制台。

> 💡 **进阶提示**：
> - **开启 HTTPS（`https://<设备名>.ts.net`）**：需要在 Tailscale 管理后台开启 **MagicDNS** 与 **HTTPS 证书**。若需使用浏览器推送通知、座舱对讲、PWA 添加到桌面或硬解推流，建议开启 HTTPS。
> - **「启用 Tailscale 代理」开关**：仅针对 **MQTT 服务路由**生效，开启后可通过 Tailnet 内网直连私有 MQTT Broker（如家里的 Home Assistant / Mosquitto），此时公网 MQTT Broker（如 HiveMQ、AWS IoT）将不可达；**不影响车机日常上网与其他 App**。

#### 🟡 方案 C：Zrok 隧道

在 `zrok.io` 注册获取 Enable Token 后填入 App，即可生成公网访问链接（`https://xxx.share.zrok.io`），无需手机装客户端。注意国内车机直连海外服务器可能存在网络波动，且免费账户有设备/隧道配额限制。

#### 🟡 方案 D：Cloudflare Tunnel

生成公网加密链接（`https://xxx.trycloudflare.com`），免客户端打开即可访问；但部分地区对 Cloudflare 延迟偏高，视频推流速度受网络线路影响较大。

#### 四种方案对比

| 维度 | 局域网直连 | Tailscale | Zrok | Cloudflare |
|---|---|---|---|---|
| 配置难度 | ⭐ | ⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐ |
| 需要公网 IP | 不用 | 不用 | 不用 | 不用 |
| 人在外地能用 | ❌ | ✅ | ✅ | ✅ |
| 手机需装客户端 | 不用 | 需装 Tailscale | 不用 | 不用 |
| 延迟与流畅度 | 最低（`<100ms`） | 低（P2P 直连） | 中（受海外链路影响） | 中（受海外链路影响） |
| 适用场景 | 家里/测试排障 | **日常主力推荐** | 临时免客户端分享 | 临时免客户端访问 |

## 5. 第四步：登录 Web 控制台并按需配置

### 5.1 输入访问码登录

首次打开 Web 控制台会要求输入 **「访问码」**：

> 在车机 **OverDrive App 左侧栏「仪表板」** 页面中，即可看到并复制 **「访问码」**。

- 访问码支持在 App 中随时重新生成；
- 登录接口自带错误限流（连续输错会被临时锁定），防止暴力破解。

### 5.2 哨兵监控与安全地点（Web 端 →「哨兵监控」）

- **触发策略与灵敏度**：支持检测区域、定时生效时段、移动灵敏度及前向 OEM 行车记录仪联动，建议先用默认参数跑几天，再按误报情况微调。
- **安全地点（Safe Locations）**：可将自家地库、单位固定车位设置为安全区域；停在安全区域内时自动停用驻车哨兵，既避免熟人来回走动频繁触发录像，也能进一步省电。
- **停车时保持 USB 供电**：使用 USB 随身 Wi-Fi 时开启。
- **低电量停止**：保护动力电池的最后一道门控（详见第 7 章）。

### 5.3 录像与存储

- 默认存放在车机内置存储 `/storage/emulated/0/Overdrive/`，可在设置中切换为 **SD 卡** 或 **USB 存储**；
- 支持设置存储空间上限，容量达到上限后自动滚动清理最旧录像。

### 5.4 通知推送（Web 端 →「通知」）

| 渠道 | 特点 | 配置方式 |
|---|---|---|
| **企业微信 / Webhook（中文版特有）** | **国内网络直连，无需代理**；支持抓拍图文、驻车耗电与行程报告 | 打开 Web 端 **「通知 → 企业微信 / Webhook」**，填入群机器人 Webhook 地址保存，点 **「发送测试通知」** 即可（兼容企微/钉钉/飞书） |
| **Telegram 机器人** | 支持双向交互命令（远程拉流/控车/查状态） | 通过 `@BotFather` 创建机器人，填入 Bot Token 与 Chat ID |
| **浏览器推送** | 手机网页/PWA 原生弹窗 | 需通过 Tailscale HTTPS 安全源打开控制台并授权通知 |

### 5.5 Home Assistant 本地联动（Web 端 →「集成 → MQTT」）

内置 MQTT 客户端，支持 Home Assistant 自动发现：将动力电量、续航、车速、四轮胎压、车内温度、门窗锁状态毫秒级推送至 HA，并支持在 HA 中反控空调、车窗、后备箱、座椅加热通风等。**全程走局域网/Tailnet 直连，不经过比亚迪云端。**

## 6. 日常怎么用

**日常开车与锁车**：配置完成后无需每次手动打开，车辆上电、熄火驻车均由后台守护进程自动接管。

**手机远程查看**：打开 Tailscale → 浏览器进入 Web 控制台，常用菜单如下（以 Web 端侧边栏名称为准）：

| 想做什么 | Web 控制台对应菜单 |
|---|---|
| 查看电量、续航、胎压、门窗状态及地图定位 | **仪表盘** |
| 实时查看 4 路高清环视画面、远程抓拍 | **实时画面** |
| 按时间/目标（行人、车辆等）/告警级别回放或下载录像 | **录像** |
| 远程锁车/解锁、闪灯鸣笛寻车、开关车窗与后备箱 | **车辆控制** |
| 查看每次驾驶里程、电耗、驾驶评分与费用估算 | **行程** |
| 查看动力电池健康度（SOH）、充电曲线与累计充电成本 | **充电** |
| 配置安全地点、USB 常电、低电量停止与灵敏度 | **哨兵监控** |
| 配置企微/微信推送、Telegram 与浏览器提醒 | **通知** |

**录像文件命名前缀含义**：

| 文件前缀 | 对应类型 |
|---|---|
| `event_` | **驻车哨兵触发事件**（找异常碰撞/可疑人员看这类） |
| `proximity_` | 原车倒车雷达近距离靠近触发 |
| `cam_` | 行车过程环视录像 |
| `dvr_` | 原厂前视行车记录仪镜像 |
| `manualClip_` | 手动抓拍/录制片段 |

## 7. 耗电实测与 12V 小电瓶保护

这是车友最关心的问题：**24 小时常驻，到底费多少电？会不会把 12V 小电瓶放亏？**

### 7.1 整套系统功耗拆解与实测参考

| 耗电部件 | 运行状态 | 功率范围 | 说明 |
|---|---|---|---|
| USB 随身 Wi-Fi | 4G/5G 蜂窝保活 | 1W ~ 1.5W | 5V × 0.2~0.3A，功耗极低 |
| 车机 SoC + 内存 | 熄屏运行，静态驻车四进程总 CPU 实测约 7.5%（8 核占比 `<1%`）；高负载峰值 `<28%` | 2.5W ~ 5W | 熄屏走的是**背光轨真实断电**，非亮度调 0 假黑屏 |
| 4 路摄像头 + ISP | 驻车低帧率捕获 | 2.5W ~ 4W | 静止时自动降帧率，大幅压低发热与功耗 |
| YOLO AI 推理 | 仅画面发生移动时介入 | 0W ~ 2W | 静态画面不空跑推理 |
| **整套系统合计** | **全天候待机运行** | **约 7W ~ 12W** | **相当于一盏家用小功率 LED 灯泡** |

### 7.2 24 小时耗电量折算

- 按 **7W ~ 10W** 日常平均待机功耗折算：
  `7~10W × 24h ≈ 0.17 ~ 0.24 度电/天`。
- **实车长稳参考**（`v49.9.37` 隔夜 14.75h + 全天 26h 实测）：全链路平均待机功耗约 **7W**，26 小时仅消耗 **1% SOC**（约 `0.9%/天`），纯电表显续航基本无感变化。

### 7.3 对比原厂高算力哨兵

| 对比项 | OverDrive | 常见高算力域控原厂哨兵 |
|---|---|---|
| 运行功率 | **7W ~ 12W** | 150W ~ 250W |
| 单日耗电 | **约 0.2 ~ 0.3 度** | 约 3 ~ 5 度 |
| 单日掉电比例 | **约 0.3% ~ 1.5%** | 5% ~ 10% |

原因在于架构差异：高算力域控哨兵需要唤醒全套智驾域控芯片；而 OverDrive 直接复用座舱车机芯片和原车全景相机，并关闭背光熄屏运行，功耗只有前者的 **1/15 ~ 1/20**。

### 7.4 会不会把 12V 小电瓶放亏？

**不会，系统层面有双重保险：**

1. **第一道 · 比亚迪原车高压智能补电**
   车机与随身 Wi-Fi 消耗 12V 蓄电池电量；当 12V 电压回落至门限区间时，原车整车控制器（VCU）会自动唤醒高压 DC-DC，从底盘动力大电池抽电把 12V 小电瓶充满后休眠。实测驻车整晚小电瓶稳定维持在 `13.0V ~ 13.8V` 安全区间并按时触发补电。
2. **第二道 · OverDrive 内置「低电量停止」门控（`SocCutoffMonitor`）**
   在 **「哨兵监控 → 低电量停止」** 中可设置阈值（默认 **10%**，支持调节 `0%` 关闭 ~ `30%`）：
   - 当动力电池 SOC 跌至阈值及以下且**非充电状态**时，等待 **60 秒防抖宽限期**；
   - 确认仍低于阈值后，自动停止保活、**释放所有 WakeLock 唤醒锁**、熄屏休眠并退出守护进程，让车辆彻底进入深度睡眠，防止过放趴窝；
   - **若车辆正在充电，则不会触发切断**。

### 7.5 停放建议

- **日常通勤（每天或隔天开）**：放心 24h 常开，每天零点几度电几乎无感知。
- **如果要长时间停放（如出差半个月以上）**：建议在 Web 端 **「哨兵监控」** 把 **「低电量停止」** 调高到 **20%**，或者直接切回 **「仅行车时」** 模式，同时利用 **「安全地点」** 避免在家/地库无效耗电。

## 8. 常见问题

**Q：装完打开，画面全黑？**
A：① 确认已完成 **长按音量滚轮/电源键 5 秒硬重启**；② 到 App **诊断 → 摄像头探测器** 将 ID 设为 `0` 保存并重启摄像头守护进程；③ 仍不行可尝试 `1`。

**Q：App 装了但无法联网、Tailscale 一直连不上？**
A：99% 是 **没有停用「比亚迪路况监测服务」**，或停用后 **没有长按硬重启车机**。

**Q：Web 控制台打不开？**
A：按顺序排查：① 车机路况监测是否已停用并硬重启 → ② App 内摄像头/Web 守护进程是否在运行 → ③ 手机和车机是否处于同一局域网，或 Tailscale 两端是否均在线。

**Q：更新系统或更新 OverDrive 后哨兵不后台自启了？**
A：每次覆盖安装后，比亚迪系统都会重置应用自启动白名单。打开一次 OverDrive，在弹出的引导框中重新放行 **「禁用自动启动限制」** 即可（也可顺手硬重启一次确认守护进程拉起）。

**Q：更新 App 会丢失以前的设置吗？**
A：**不会。** 本仓库构建采用固定签名指纹，支持直接覆盖升级，所有参数持久化保存在车机 `/data/local/tmp/overdrive_config.json`，摄像头映射、自动化规则和通知配置都会自动保留。

**Q：会耗光小电瓶或很费电吗？**
A：不会，实测全天候平均待机功耗约 **7W~12W**（每天约 0.2~0.3 度电），原车有自动高压补电，OverDrive 也自带默认 10%「低电量停止」保护，具体原理与实测数据详见 [第 7 章](#7-耗电实测与-12v-小电瓶保护)。

**Q：忘记 App PIN 锁密码怎么办？**
A：电脑通过 USB 调试连接车机，运行下面命令清除，无需卸载或恢复出厂：
```bash
adb shell touch /data/local/tmp/.overdrive_pin_reset
```

## 9. 安全与隐私

- **100% 本地闭环**：所有行车视频、哨兵事件与位置轨迹都只留在车机本地，不经过任何第三方云服务器，无强制登录、无月费。
- **访问认证保护**：Web 控制台支持访问码登录与错误尝试限流保护。
- **使用时的四条安全底线**：
  1. 若开启 **Zrok / Cloudflare Tunnel** 等公网穿透，相当于控制台直接暴露在公网，请务必设置复杂访问码，切勿把链接发到公开群聊；**日常强烈推荐仅使用带设备鉴权的 Tailscale**。
  2. OverDrive 依赖 ADB 权限读取传感器与摄像头，代码完全开源可审计，请仅从官方/可信仓库的 Release 下载签名安装包。
  3. **不要在「自动化」规则里随意添加执行 Shell 命令的动作**，除非你完全理解命令含义。
  4. 哨兵录像及定位截图包含车辆周边真实环境与个人行踪，对外分享前注意打码脱敏。
